# ASU runtime audit matrix

Measured SPEC-3 properties of each runtime's documented human-approval / confirmation mechanism. Generated by `python audit/run_all.py`.

Outcome legend: **PASS** = property holds · **FAIL** = property missing · **PART** = holds only partially · **n/a** = no such mechanism / not applicable · **not_run** = not executed.

Markers: **†** = fails BY CONSTRUCTION under SPEC-3's host-adversarial threat model (not a measured per-runtime result; EXCLUDED from any “N of M” count) · **-s / ˢ** = static source review only, never executed (capped below PASS) · **PART/INT** = holds only if the integrator renders from the structured data · **PART(STORE)** = bound against the resumer but not a backing-store writer · **PART(STATE)** = single use is relative to run state; a rollback replays · **PART(LOW)** = low-severity gap · **[J]** = JUDGEMENT: the outcome is a hard-coded literal chosen by the auditor from source/doc/API review (rationale in the row), not selected by an observed experimental value; EXCLUDED from the measured counts like † cells.

Columns P1-P7 correspond to tests T1-T6 (see each probe docstring).
